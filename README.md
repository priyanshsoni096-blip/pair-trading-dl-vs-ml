# Pair Trading: ML vs DL — KOTAK ↔ HDFC Bank

A full-stack algorithmic trading system comparing Machine Learning and Deep Learning models for pair trading between KOTAK Bank and HDFC Bank stocks.

## Team
- Priyansh Soni — DevOps, Docker, Jenkins
- Arnav Rathod — ML Engineer (RF, SVR, Data Pipeline)
- Keertan Soni — DL Engineer (LSTM, CNN-LSTM, Backtesting)

## Models
| Model | RMSE | R² |
|---|---|---|
| Random Forest | 0.3732 | 0.919 |
| SVR (RBF) | 0.4663 | 0.874 |
| LSTM | 0.7780 | 0.648 |
| CNN-LSTM | 0.8463 | 0.583 |
