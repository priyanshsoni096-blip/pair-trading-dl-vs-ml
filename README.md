# Pair Trading: ML vs DL

This project compares Machine Learning and Deep Learning models for pair trading strategy.

## Models Used
- Random Forest
- SVR (Support Vector Regression)
- LSTM
- CNN-LSTM

## Features
- Technical indicators
- Cointegration analysis
- Backtesting

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow
- Docker
- Jenkins
